# 🚀 Assistente de programação para Arduino

> Ambiente web educacional, que utiliza Inteligência Artificial Generativa para apoiar a construção de códigos para Arduino a partir de descrições em linguagem natural fornecidas pelos estudantes.

---

## 💻 Sobre o Projeto

Observa-se que os estudantes de Ensino Médio apresentam dificuldade para programar o Arduino de forma tradicional,  
escrevendo o código em C/C++ na IDE da plataforma, o que resulta em dificuldades para realizar atividades experimentais  
de Física, no estudo de Lei de Ohm, circuitos elétricos, geradores e receptores, além de outros. O assistente é uma  
proposta para orientar o estudante na criação do código, desde a elaboração do algoritmo, até a fase de testes. Desse  
modo, espera-se que ocorra aprendizagem significativa dos conceitos de Física, além da programação básica do Arduino.
